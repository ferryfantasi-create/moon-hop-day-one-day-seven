Moon Hop is a tiny agent-built game: a little moon hops across floating
islands and collects stars. Day one it was grey, three platforms and one
star. After a week of daily updates it has a sky, clouds, coins, a bat
enemy, particles and a score. The video for this bounty cuts between the
same moments a week apart, same map, same start, camera still, and ends
with make.fun's referral end card.

## Play it

Open `index.html` in a browser. Press Space (or tap) to hop to the next
island. Collect stars, dodge the bat.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `VIDEO.json` — the
address of the TikTok video — to `/output/VIDEO.json`. That is all it
has to do; the video itself is the entry.
